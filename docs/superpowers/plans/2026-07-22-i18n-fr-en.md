# Site bilingue FR/EN avec next-intl — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre le site AKILI Labs bilingue : français à la racine (URLs inchangées), anglais sous `/en/`, sélecteur manuel FR/EN, SEO bilingue complet.

**Architecture:** next-intl 4.x avec `localePrefix: "as-needed"`. Toutes les pages migrent dans `src/app/[locale]/`. Les textes en dur des composants sont extraits vers `messages/fr.json` / `messages/en.json` ; les fichiers `src/lib/*-data.ts` passent leurs champs textuels en `{ fr, en }` résolus par un helper `localize()`. Un `LanguageSwitcher` bascule vers la même page dans l'autre langue.

**Tech Stack:** Next.js 16 (App Router, `proxy.ts` — PAS `middleware.ts`), next-intl ^4.13, React 19, Tailwind 4, TypeScript.

## Global Constraints

- **Spec de référence :** `docs/superpowers/specs/2026-07-22-i18n-fr-en-design.md` — la lire avant toute tâche.
- **Next.js 16 a des breaking changes** : lire `node_modules/next/dist/docs/` en cas de doute (règle AGENTS.md du repo). Le middleware s'appelle désormais `proxy.ts`.
- **Locales :** `fr` (défaut, sans préfixe d'URL) et `en` (préfixe `/en`). Slugs français conservés sous `/en/`.
- **Non-régression FR absolue :** le texte français extrait doit être STRICTEMENT identique au texte actuel (copier-coller, pas de reformulation). Le rendu FR ne doit pas changer d'un pixel.

Ne jamais traduire : Odoo, OHADA, UEMOA, DevSecOps, XOF, noms propres, noms de modules Odoo. « TMA » → garder le sigle avec « (application maintenance) » à la première occurrence de chaque page. « Appel d'offres » → "tender". « Schéma Directeur » → "IT Master Plan". « SIRH » → "HRIS". « Maîtrise d'ouvrage/d'œuvre » → "project owner / project management".
- **Domaine canonique :** `https://akililabs.io` (remplacer TOUTES les occurrences de `akililabs.com`).
- **Pas de framework de test dans ce repo.** Le cycle de vérification de chaque tâche est : `npm run build` (doit passer sans erreur ni warning nouveau) + `npm run lint` + contrôle du rendu via `npm run dev` et curl/navigateur.

```ts
import { getRequestConfig } from "next-intl/server";
import { hasLocale } from "next-intl";
import { routing } from "./routing";

type Messages = Record<string, unknown>;

function deepMerge(base: Messages, override: Messages): Messages {
  const result: Messages = { ...base };
  for (const key of Object.keys(override)) {
    const b = base[key];
    const o = override[key];
    if (b && o && typeof b === "object" && typeof o === "object" && !Array.isArray(b) && !Array.isArray(o)) {
      result[key] = deepMerge(b as Messages, o as Messages);
    } else {
      result[key] = o;
    }
  }
  return result;
}

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  const fr = (await import("../../messages/fr.json")).default as Messages;
  const messages =
    locale === "fr"
      ? fr
      : deepMerge(fr, (await import("../../messages/en.json")).default as Messages);

  return { locale, messages };
});
```

- [ ] **Step 1: Créer le composant**

```tsx
"use client";

import { useLocale } from "next-intl";
import { usePathname, useRouter } from "@/i18n/navigation";
import { cn } from "@/lib/utils";

const locales = [
  { code: "fr", label: "FR" },
  { code: "en", label: "EN" },
] as const;

export default function LanguageSwitcher({ className }: { className?: string }) {
  const locale = useLocale();
  const pathname = usePathname();
  const router = useRouter();

  return (
    <div className={cn("flex items-center gap-1 text-sm font-semibold", className)}>
      {locales.map(({ code, label }, i) => (
        <span key={code} className="flex items-center gap-1">
          {i > 0 && <span className="text-gray-300">|</span>}
          <button
            type="button"
            onClick={() => router.replace(pathname, { locale: code })}
            aria-current={locale === code ? "true" : undefined}
            className={cn(
              "px-1 transition-colors",
              locale === code
                ? "text-[#1A2B3C] border-b-2 border-[#FF5500]"
                : "text-[#374151] hover:text-[#1A2B3C]"
            )}
          >
            {label}
          </button>
        </span>
      ))}
    </div>
  );
}
```

- [ ] **Step 1: Créer le helper**

`src/lib/i18n-content.ts` :

```ts
export type Localized = { fr: string; en: string };

export function l(value: string | Localized, locale: string): string {
  if (typeof value === "string") return value;
  return locale === "en" ? value.en : value.fr;
}
```

(Les champs non traduisibles — slugs, couleurs, icônes, URLs — restent des `string` simples ; `l()` les renvoie tels quels, ce qui permet une migration champ par champ.)

- [ ] **Step 1: Helper SEO**

`src/lib/seo.ts` :

```ts
export const BASE_URL = "https://akililabs.io";

export function buildAlternates(path: string, locale: "fr" | "en") {
  const frUrl = path === "/" ? BASE_URL : `${BASE_URL}${path}`;
  const enUrl = `${BASE_URL}/en${path === "/" ? "" : path}`;
  return {
    canonical: locale === "fr" ? frUrl : enUrl,
    languages: { fr: frUrl, en: enUrl, "x-default": frUrl },
  };
}
```

```ts
function entry(path: string, opts: Partial<MetadataRoute.Sitemap[number]> = {}) {
  const fr = path === "" ? BASE_URL : `${BASE_URL}${path}`;
  const en = `${BASE_URL}/en${path}`;
  return {
    url: fr,
    lastModified: new Date(),
    alternates: { languages: { fr, en } },
    ...opts,

}
```
